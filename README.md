# Yumi v1.0 — Kurulum

[Yumi](https://github.com/AEDogan/Yumi_v1.0) masaüstü sesli asistanının Windows kurulumu (Windows 10/11, 64 bit).

Kurulum dosyaları **[Releases](../../releases/latest)** sayfasındadır.

## Kurulum
1. Son sürümdeki **`Yumi-Kurulum-1.0.0.exe`**, **`1` … `7`** parçalarının hepsini ve **`Birlestirici.cmd`**'yi aynı klasöre indirin.
2. **`Birlestirici.cmd`**'ye çift tıklayın: parçalar birleşir, kontrol edilir ve kurulum kendiliğinden başlar.
3. Kurulum bitince parçaları silebilirsiniz.

GitHub tek dosyada 2 GB sınırı koyduğu için kurulum verisi 7 parçadır (toplam ~12,6 GB).

## Karakterler (modeller)
Kurulum yalnız Yumi uygulamasıdır; karakter modelleri ayrı indirilir:
**[Anime karakter seti → yumi-models / anime-1.1.0](https://github.com/AEDogan/yumi-models/releases/tag/anime-1.1.0)**

İndirdiğiniz paketi Yumi → **Model → + Paket ekle** ile ekleyin.
